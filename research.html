MSc Dissertation

Quantifying the Effectiveness and Implications of Data Cleaning

Examining how different cleaning strategies change model outcomes — not just how tidy the dataset looks. Key findings include the vocabulary cliff effect, silent data loss, and model-cleaning interaction, each documenting ways that well-intentioned cleaning decisions can silently degrade model performance. The work is currently being prepared for publication in Machine Learning (Springer).

Applied Work

My deployed projects serve as practical demonstrations of my research interests. The vehicle damage classifier explores model evaluation under real‑world noise, comparing a custom CNN with MobileNetV2 transfer learning. The SMS spam detector examines class imbalance and metric selection, showing how accuracy can fail while recall and F1 reveal the true behaviour of a model.

Both agent versions revealed dataset drift against modern patterns — a direct empirical connection to the vocabulary cliff effect documented in my dissertation.
