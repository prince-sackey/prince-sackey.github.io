SMS Spam Detection Agent

Python · scikit-learn · TF-IDF · Linear SVM · Groq API · LLaMA · Streamlit

An upgrade of the original SMS spam detector — the Linear SVM classifier is wrapped with an AI agent that explains why a message looks like spam, interprets confidence scores in plain English, and recommends specific actions. Testing revealed dataset drift against modern spam patterns — documented as a research finding connecting to the vocabulary cliff effect from my MSc dissertation.

SMS Spam Detection

Python · scikit-learn · TF-IDF · Linear SVM · Streamlit · HuggingFace Spaces

A binary classifier distinguishing spam from legitimate SMS messages, comparing Logistic Regression, Linear SVM, BiLSTM, and CNN models. Linear SVM won via 5-fold cross-validation, beating a majority-class baseline (87% accuracy, but 0% spam recall) — showing why raw accuracy is the wrong metric for imbalanced classification problems.
