Vehicle Damage Assessment Agent

Python · ONNX · FastAPI · Docker · Azure Container Apps · Groq AI

An AI agent that classifies vehicle damage from an uploaded photo, explains the damage professionally, recommends repair urgency, and generates a downloadable insurance assessment report. Built on a MobileNetV2 model (84% accuracy) converted to ONNX and served via a FastAPI backend deployed on Azure Container Apps. Includes a confidence threshold — if the model is uncertain, the agent requests a clearer image rather than guessing.

SMS Spam Detection Agent

Python · scikit-learn · TF-IDF · Linear SVM · FastAPI · Docker · Azure Container Apps · Groq AI

An AI agent that classifies SMS messages as spam or ham, explains why in plain English, interprets confidence scores, and recommends specific actions. Built on a Linear SVM pipeline (98.6% accuracy) served via FastAPI on Azure Container Apps. Testing revealed dataset drift against modern spam patterns — documented as a research finding connecting to the vocabulary cliff effect from my MSc dissertation.

SMS Spam Detector

Python · scikit-learn · TF-IDF · Linear SVM · Streamlit · HuggingFace Spaces

A binary classifier distinguishing spam from legitimate SMS messages, comparing Logistic Regression, Linear SVM, BiLSTM, and CNN models. Linear SVM won via 5-fold cross-validation, beating a majority-class baseline (87% accuracy, 0% spam recall) — showing why raw accuracy is the wrong metric for imbalanced classification. The foundation for the agent version above.
